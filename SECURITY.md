# Security policy

Swiss Alternatives is a static website: there is no backend, no database, no
user accounts and no cookies. Interactive features store data only in the
visitor's own browser.

## Reporting a vulnerability

Please report security issues **privately** to the address on the [contact page](https://swiss-alternatives.ch/contact/)
(subject: "Security report") rather than opening a public issue. Include steps
to reproduce and the affected URL or file. We will acknowledge the report and
keep you informed while we fix it.

Relevant areas include the Content-Security-Policy, the build and deployment
pipeline, GitHub Actions workflows, and any way to inject content into pages
through the data files.

The site's security contact is also published at
`/.well-known/security.txt`.
